# 🧠 MBTI Content Recommendation System

> ML-система персонализации контента на основе психоанализа текстов и изображений. 
> Решает проблему холодного старта (+211% MRR) и автоматизирует профилирование пользователей.


[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)]()

## 💡 Ключевые бизнес-результаты
- **+211% MRR** рекомендательной системы по сравнению с базовыми методами
- **48% Accuracy** классификации 16 типов личности (SOTA уровень для русскоязычных текстов)
- **64% Accuracy** визуального анализа профилей (+8 п.п. к существующим решениям)
- Внедрено в **ООО «Оллкьюб»** для повышения пользовательской вовлеченности

## 🛠️ Стек технологий
**ML/DL:** PyTorch, Transformers (DistilBERT, CLIP), PEFT (LoRA/DoRA), XGBoost, LightGBM  
**Data:** Pandas, NumPy, Scikit-learn, HuggingFace Datasets  
**Инфраструктура:** Accelerate, AMP (FP16), WeightedRandomSampler  
**Визуализация:** Matplotlib, Seaborn, t-SNE  

## 📊 Основные метрики
| Компонент | Метрика | Значение | Улучшение |
|-----------|---------|----------|-----------|
| Рекомендации | MRR | 0.513 | +211% vs baseline |
| Текст (16 классов) | Macro-F1 | 0.432 | SOTA |
| Визуал (4 дихотомии) | Avg Accuracy | 64% | +8 p.p. vs SOTA |
| Cold-Start | Soft P@10 | 0.361 | +28% vs Global Mean |

## 🏆 Сравнение с существующими решениями

Мы провели валидацию наших моделей против признанных baseline-решений в задачах предсказания MBTI по тексту и изображениям.

### 📝 Текстовый канал (Textual Personality Detection)
**Baseline:** Zhu H. *Integrating Multi-view Analysis: Multi-view Mixture-of-Expert for Textual Personality Detection*

| Метрика (Дихотомия) | Baseline (Zhu et al.) | Наше решение | Разница (Δ) |
|:---|:---:|:---:|:---:|
| **E/I** (Экстраверсия) | 65.02% | **80.70%** | 🟢 +15.68 |
| **S/N** (Интуиция) | 59.56% | **91.92%** | 🟢 +32.36 |
| **T/F** (Логика) | 78.45% | 77.31% | 🔴 -1.14 |
| **J/P** (Рациональность) | 65.54% | **71.12%** | 🟢 +5.58 |
| **Avg. Accuracy** | 67.14% | **80.26%** | 🟢 **+13.12** |

### 🖼️ Визуальный канал (Personality from Facial Images)
**Baseline:** Gan P. Z., Sowmya A., Mohammadi G. *Personality Perception From Facial Images // AI 2022*

| Метрика (Дихотомия) | Baseline (Gan et al.) | Наше решение | Разница (Δ) |
|:---|:---:|:---:|:---:|
| **E/I** (Экстраверсия) | 56.90% | **64.07%** | 🟢 +7.17 |
| **S/N** (Интуиция) | 55.90% | **64.75%** | 🟢 +8.85 |
| **T/F** (Логика) | 58.50% | **64.30%** | 🟢 +5.80 |
| **J/P** (Рациональность) | 56.50% | **60.25%** | 🟢 +3.75 |
| **Avg. Accuracy** | 56.95% | **63.34%** | 🟢 **+6.39** |

> 💡 **Примечание:** В текстовом канале мы незначительно уступаем baseline по метрике T/F (-1.14%), однако компенсируем это рекордным приростом по S/N (+32.36%) и общей средней точности (+13.12%). В визуальном канале наше решение превосходит baseline по **всем** дихотомиям.
